A make.fun bounty entry: a program that writes exactly one line roasting
the fridge — at most 200 characters, nothing else — to `/output/entry.txt`.

The roast:

> My fridge treats the crisper drawer like a witness protection program: the lettuce goes in crisp, comes out unrecognizable, and never talks again.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

Python standard library only, deterministic — every run writes the same
single line.
